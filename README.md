# probe

**An adaptive interviewing agent, and the offline harness that measures whether it actually works.**

The eval harness is the project; the interviewer is the subject.

`probe` exists to answer three questions with numbers and confidence intervals:

1. **Efficiency** — does an expected-information-gain question policy reach a target confidence in fewer questions than a fixed script, at equal skill-recovery accuracy?
2. **Grader reliability** — what is the LLM grader's test–retest variance, position bias, and self-consistency?
3. **Style invariance** — how much does candidate surface style move scores independent of content, and can the drift be engineered down?

## Quick start

```bash
uv sync --all-extras
make test
```

Run a single fully-offline interview and persist it to the trace store:

```bash
uv run probe run --fake --persona stub --questions 5
```

## Layout

| Path | What lives there |
|---|---|
| `probe/rubric/` | Fixed competency taxonomy and the rubric compiler |
| `probe/belief/` | Grid posterior, graded-response likelihood, IRT calibration |
| `probe/policy/` | The four arms: `fixed`, `heuristic`, `eig`, `eig+corr` |
| `probe/bank/` | Question bank and follow-up generation |
| `probe/grader/` | Rubric grader, span validation, flag classifiers |
| `probe/sim/` | Persona generator — the measurement plane's candidates |
| `probe/runtime/` | Interview loop, budgets, repair ladder, tracing, provider boundary |
| `evals/` | Metric families and the suites that run them |
| `analysis/` | Notebooks and generated artefacts |
